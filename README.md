# Поиск всех простых циклов в ориентированном графе

Курсовая работа по дисциплине **«Алгоритмы и структуры данных»**.

Проект посвящён поиску полного множества простых циклов в ориентированном графе с использованием **алгоритма Джонсона**.

## О проекте

Пусть задан ориентированный граф

\[
G = (V, E),
\]

где:

- `V` — множество вершин;
- `E` — множество ориентированных рёбер.

Необходимо найти все **простые циклы** графа — такие последовательности вершин, которые:

- начинаются и заканчиваются в одной вершине;
- учитывают направление рёбер;
- не содержат повторяющихся вершин внутри цикла.

Для решения задачи используется алгоритм Джонсона, предназначенный для эффективного поиска всех простых циклов ориентированного графа без дублирования результатов.

## Представление графа

Граф хранится в виде **списка смежности**.

Такой способ представления выбран потому, что:

- требует меньше памяти для разреженных графов по сравнению с матрицей смежности;
- позволяет быстро получать список исходящих рёбер вершины;
- удобен для обхода графа;
- хорошо подходит для алгоритмов поиска циклов.

## Алгоритм

В основе решения лежит **алгоритм Джонсона**.

Основные этапы:

1. Выбирается подграф, в котором потенциально могут находиться циклы.
2. Определяются **сильно связные компоненты**.
3. Выбирается стартовая вершина.
4. Запускается обход в глубину (`DFS`).
5. Для предотвращения повторного обхода используются блокировка и разблокировка вершин.
6. При возвращении в стартовую вершину найденный простой цикл сохраняется.
7. Процесс повторяется до нахождения всех циклов графа.

Использование сильно связных компонент позволяет не выполнять поиск в частях графа, где циклы заведомо отсутствуют.

## Временная сложность

Временная сложность алгоритма Джонсона:

\[
O((|V| + |E|)(C + 1)),
\]

где:

- `|V|` — количество вершин;
- `|E|` — количество рёбер;
- `C` — количество найденных простых циклов.

Количество циклов в графе в общем случае может быть экспоненциальным, поэтому время работы алгоритма естественным образом зависит от размера результирующего множества.

## Возможности программы

В рамках проекта реализованы:

- работа с ориентированным графом;
- представление графа с помощью списка смежности;
- поиск всех простых циклов;
- исключение повторяющихся циклов;
- использование сильно связных компонент;
- вывод найденных циклов;
- вывод матрицы смежности для проверки исходного графа;
- измерение времени выполнения алгоритма.

## Пример

Для тестового графа программа выводит матрицу смежности, количество найденных циклов и сами циклы.

Пример результата:

```text
Number of simple cycles: 2

C1 = (0, 1, 2)
C2 = (1, 3, 4)
```

Также программа выводит время выполнения алгоритма.

## Практическое применение

Поиск циклов в ориентированных графах может использоваться при решении задач:

- анализа сетевых структур;
- поиска циклических зависимостей;
- анализа зависимостей между объектами;
- проверки моделей и схем;
- анализа маршрутов и состояний;
- исследования структур данных, представимых в виде графов.
